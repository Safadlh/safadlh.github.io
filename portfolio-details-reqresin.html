Reqres.in API Testing

Newman Report

Here is a collection of automated test scenarios to verify the API functionality of `https://reqres.in/`. Each request includes assertions for the status code, response time, response body, and other variables.

This project focuses on API testing and basic automation using Postman and Newman on the Reqres.in platform.

The objective of this project is to validate API functionality, ensure correct request and response behavior, and automate test execution using command-line tools.

  • Understanding API structure and JSON format
  • Validating response data and status codes
  • Designing effective test scenarios for each endpoint
  • Handling different HTTP methods (GET, POST, PUT, DELETE)
  • Executing automated API testing using CLI (Newman)

  • Created API test scenarios in Postman collections
  • Tested endpoints using multiple HTTP methods
  • Validated response status codes and body structure
  • Implemented test scripts for response validation
  • Executed automated testing using Newman

Key Features

  • API Functional Testing
  • Request & Response Validation
  • Status Code Verification
  • CRUD Testing (Create, Read, Update, Delete)
  • Positive & Negative Testing
  • API Automation Testing (Newman)
