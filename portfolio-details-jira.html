UI Testing and Bug Reporting


This project focuses on performing User Interface (UI) testing by comparing application screens with provided design references. The objective is to ensure visual consistency and identify discrepancies between the expected design and the actual implementation.

Testing was conducted by analyzing UI elements such as layout, typography, colors, icons, and text content. Identified issues were documented and reported using Jira.

  • Identifying UI inconsistencies compared to design
  • Ensuring consistency in UI elements such as alignment, spacing, and typography
  • Detecting incorrect icons, text, and color usage
  • Writing clear and reproducible bug reports
  • Determining appropriate severity and priority levels

  • Conducted UI comparison testing between application screens and design references
  • Validated layout, text content, icons, and visual elements
  • Identified inconsistencies and visual defects
  • Documented bugs in a structured format using Jira
  • Assigned severity and priority based on impact

Testing Scope

  • UI Testing
  • Visual Validation (Design vs Implementation)
  • Bug Reporting
  • Severity & Priority Analysis
  • Usability Observation

Tools and Technologies

  • Bug Tracking Tool: Jira
  • Design Reference: Provided UI mockups (image-based)
  • Platform: iOs

Key Findings

  • Text content inconsistencies compared to design
  • Misalignment of UI elements
  • Incorrect icon orientation and positioning
  • Differences in color and typography
  • UI spacing issues

Summary

    This project demonstrates the ability to perform UI validation and identify visual inconsistencies through detailed comparison testing. It highlights the importance of attention to detail and structured bug reporting in improving overall product quality.
